# Archives

Closed, one-off lessons that are unlikely to recur — a specific incident, an external outage, a since-fixed upstream bug, a project that no longer exists. Organize however is convenient, e.g. by year: `2026/2026-08-checkout-outage.md`.

Archives exist so the log doesn't get lost, but `/mistake-brain route` and `/mistake-brain dream` should not surface these for active decision-making — they're historical record, not live guidance.
