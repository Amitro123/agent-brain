# Resources

General, reusable principles that aren't tied to a specific project or domain — things that would still be true in a different codebase, e.g. `error-handling-principles.md`, `code-review-checklist.md`. These are the closest thing to "wisdom" in this memory: patterns worth remembering regardless of context.

Same entry format as Projects/Areas. Resources are the most common source of `/mistake-brain promote` candidates, since a principle that keeps proving itself is exactly what a CLAUDE.md rule is for.
