# Projects

One file per active project/feature this agent is working on, e.g. `checkout-redesign.md`, `PROJ-482-oauth-migration.md`. Name it after however the current task refers to the work (branch name, ticket ID, feature name) so `/mistake-brain route` and future sessions can match it back up.

Each file is a running list of lessons for that project, newest first:

```md
# <project name>

## [YYYY-MM-DD] <short title>
<what to do differently, in one or two sentences>
Source: MISTAKES.md entry [YYYY-MM-DD HH:MM] <title>
```

When a project finishes or goes quiet for a long time, `/mistake-brain dream` will flag its file as a candidate to move into `Archives/` (or `Areas/` if the lessons turned out to be general, not project-specific) — always with your confirmation, never silently.
