# Areas

One file per ongoing responsibility that outlives any single project — a domain this agent keeps coming back to, e.g. `auth.md`, `ci.md`, `db-migrations.md`, `deploy.md`. Unlike Projects, Areas are never "done."

Same entry format as Projects (newest first, with a `Source:` back-reference to the original MISTAKES.md entry). If an Area file accumulates the same root cause 3+ times, `/mistake-brain promote` will flag it as a rule candidate.
